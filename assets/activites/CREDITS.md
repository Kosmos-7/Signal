# Illustrations par activité — provenance et licences

Une photographie par ACTIVITÉ, pas par société. La sonde du 02/08 a mesuré
qu'une recherche automatique de photos libres société par société se trompe
dans 43 % des cas, avec des erreurs du type le plus grave pour un site
financier : le siège d'Asahi Mutual Life pour Shin-Etsu, une caserne de
pompiers pour Applied Materials, une photo d'Apollo 14 pour ASE Group.
Publier le bâtiment d'une entreprise sur la fiche d'une autre est un fait faux.

Chaque fiche affiche donc l'image de l'activité qu'exerce le titre, avec une
légende qui le dit. C'est vrai par construction, et cela rappelle où le titre
se situe dans la chaîne.

Contrainte inchangée : domaine public ou CC0 exclusivement, aucune attribution
obligatoire. Le crédit ci-dessous est donné par honnêteté, pas par obligation.
